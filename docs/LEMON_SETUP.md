# Lemon Squeezy の審査に出すまで

Lemon Squeezy（以下 LS）は新規ストアを人が確認し、本人確認（KYC）と事業の確認（KYB）を行う。
見られるのは主に次の点（[Activate Your Store](https://docs.lemonsqueezy.com/help/getting-started/activate-your-store) /
[Prohibited Products](https://docs.lemonsqueezy.com/help/getting-started/prohibited-products)）。

- 公開中のサイトがあり、**何を・いくらで売っているか**が分かる
- 連絡先、利用規約、プライバシーポリシー、返金ポリシーがある
- 販売物が禁止商品ではなく、**知的財産権を自分たちが持っている**

承認までは通常 1〜3 営業日。本人確認書類の提出を求められることがある。

## チェックリスト

### サイト（対応済み）

- [x] 商品一覧・商品ページ（品番・価格・収録点数・形式・説明）
- [x] 購入ボタン → LS のチェックアウト
- [x] 審査中はテストモードである旨を商品ページに明記（本番キーに替えると自動で消える）
- [x] 利用規約 / プライバシーポリシー / 返金ポリシー / ライセンス / FAQ / お問い合わせ
- [x] 「受託制作ではなく既製データの販売」「全点オリジナルで著作権は当方」と明記
- [x] 独自ドメイン drop-world.com で公開

### LS（オーナーが行う）

- [ ] **テストモードで商品を作る**（最低でも harajuku.ai の3点）→ [POSTING.md](POSTING.md) の手順と末尾の文言
- [ ] テストモードの API キーを作り、GitHub のシークレットに登録 → サイトに商品が出ることを確認
- [ ] ストア設定: ストア名、ストア URL（`https://drop-world.com`）、サポート用メール
- [ ] 相方を Teams に招待
- [ ] 振込先（Payouts）
- [ ] **Activate your store** から申請。本人確認・事業内容の質問には正直に答える

### サイトの残り（情報が必要）

- [ ] **`support@drop-world.com` を実際に受信できるようにする**（Cloudflare Email Routing → [DEPLOY.md](DEPLOY.md#サポート用メール)）
- [ ] **特定商取引法に基づく表記**の空欄: 販売業者 / 運営責任者 / 所在地 / 電話番号（`content/tokushoho.ts`）。
      所在地と電話番号は「請求があったら遅滞なく開示します」という書き方も認められている

## 申請フォームで聞かれそうなことの答え方

| 質問 | 答えの方針 |
| --- | --- |
| 何を売っているか | 建築図面用の CAD 添景データ（人物・植栽・動物）。DWG / AI のダウンロード販売 |
| 誰が作っているか | 運営者2名が自分で作図したオリジナル。他社素材の転売ではない |
| 価格帯 | 1セット $9.99〜$14.99 程度の買い切り |
| 配信方法 | LS のファイル配信（購入後に zip をダウンロード） |
| サービス（受託）を含むか | 含まない。既製のデータファイルのみ |
