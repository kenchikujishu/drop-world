# Lemon Squeezy の審査に出すまで

Lemon Squeezy（以下 LS）は新規ストアを人が確認する。公式には次の2段階
（[Activate Your Store](https://docs.lemonsqueezy.com/help/getting-started/activate-your-store)）。

1. **事業と顧客についての短い質問票**に答える
2. **本人確認**（KYC / KYB）

審査は通常 **2〜3 営業日**。申請が混み合うと伸びる。
禁止商品でないこと、**売っているものの権利を自分たちが持っていること**が確認される
（[Prohibited Products](https://docs.lemonsqueezy.com/help/getting-started/prohibited-products)）。

> LS は **Merchant of Record**。購入者に対して売るのは LS で、drop world は LS にデータを供給する立場になる。
> 決済・税の計算と納付・領収書・ファイル配信はすべて LS が行う。

## 1. 申請前に用意するもの（オーナー）

| 項目 | 内容 |
| --- | --- |
| 本人確認書類 | パスポート または 運転免許証の画像。LS の画面から提出する |
| 氏名・生年月日・住所 | LS に登録する事業者情報（**サイトには出ない**） |
| 事業形態 | 個人事業（屋号「drop world」／運営責任者 宮地凌央） |
| 受取方法 | 日本の銀行口座 または PayPal。**日本は銀行振込に対応**している |
| 銀行口座の情報 | 銀行名・支店・口座番号・名義（英字）。SWIFT を聞かれることがある |
| 税務書類 | 米国以外の個人なので、求められたら **W-8BEN**。LS の画面から入力できる |
| ストア URL | `https://drop-world.com` |
| サポート用メール | `support@drop-world.com`（**受信できる状態にしてから**申請する） |

入金の条件（[Getting Paid](https://docs.lemonsqueezy.com/help/getting-started/getting-paid)）:
**最低 $50**、月2回（1日・15日に作成、売上は13日間保留）、**支払いは USD**。

## 2. 質問票への答え方

| 聞かれること | 答えの方針 |
| --- | --- |
| 何を売っているか | 建築図面用の CAD 添景データ（人物・植栽・動物）。DWG / AI のダウンロード販売 |
| 顧客は誰か | 世界中の建築設計事務所・学生。表示は英語と日本語、価格は USD |
| 誰が作っているか | 運営者2名が自分で作図したオリジナル。他社素材の転売ではない |
| 価格帯 | 1セットごとの買い切り |
| 配信方法 | LS のファイル配信（購入後に zip をダウンロード） |
| サービス（受託）を含むか | 含まない。既製のデータファイルのみ |
| 実績・トラフィック | 新規。まだ販売実績はない、と正直に答える |

## 日本の特商法について

**LS の審査に特商法の表記は必要ない**（LS は米国の会社で、見ているのは英語の規約・返金・連絡先）。
それでも `content/tokushoho.ts` のページを置いているのは、次の理由。

- 運営は日本にあり、サイトは日本語でも販売している。日本の購入者に対する **通信販売** にあたる
- 日本の購入者・法人は、この表記が無いサイトを警戒する（社内の購買規程で通らないことがある）
- 出しておいて損がない。消す理由が無い

価格を USD にしたので、表記の「販売価格」は
**「各商品ページに表示された米ドル（USD）建ての金額」**に直した（税は LS が計算・納付する旨を併記）。

所在地・電話番号は「ご請求があったら遅滞なく開示します」としている。
**開示の請求が来たら、遅滞なく（数日以内に）答えること。** 断ると法令違反になる。
